This is my Module 5 Memory Game Assignment: AI-Assited Web Development
Objective: Create your first working memory game using AI assistance.

Write Your Initial Prompt
Open your chosen AI tool.
Write a detailed prompt requesting a memory matching game.
Your prompt must include:
A request for a "complete HTML file" with "embedded CSS and JavaScript."
A specific grid size (suggested: 4x4 with 16 cards and 8 pairs).
A description of game mechanics (flip cards, find matches, flip back if no match).
Basic styling requirements.
A win condition (what happens when all pairs are found).
