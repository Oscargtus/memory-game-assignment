## 🧠 Assignment Brief

The initial prompt had to request:

- A complete HTML file with embedded CSS and JavaScript
- A specific grid size (4x4 with 16 cards and 8 pairs)
- The game mechanics: flip cards, find matches, flip back if there is no match
- Basic styling requirements
- A win condition (what happens when all pairs are found)
